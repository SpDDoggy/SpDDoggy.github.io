OPEN DIRECTLY

三种数据，一套入口。

从文件、文件夹、最近项目或拖放进入同一套查看流程。

.gdb

File Geodatabase

直接打开数据库文件夹，浏览图层、属性、空间预览并进行支持范围内的编辑。

.shp

Esri Shapefile

联合查看几何与属性，并可将结果输出为新的 Shapefile 或文件地理数据库。

.mdb

Personal Geodatabase

使用内置 Jet4 读取器打开，无需额外安装 Access、ACE 或 ODBC 组件。

CORE WORKFLOW

从打开到导出，保持轻量。

01

直接预览

勾选图层后立即进入地图，图形、属性表和选中状态保持联动。

02

轻量编辑

按字段类型校验输入，保存前保留待提交状态，并支持撤销写回。

03

完整导出

导出属性表 CSV、单个要素 SHP，或将数据源另存为新的 GDB。

ONE FLOW

把空间数据工作，收进四步。

不改变数据结构，也不把浏览、编辑与导出混在同一个动作里。

  1. 01

    打开数据源

    选择 GDB 文件夹、SHP 或 MDB，也可以通过文件关联和拖放直接进入。

  2. 02

    检查目录与属性

    从树状目录定位图层，在属性表中搜索、排序并查看字段内容。

  3. 03

    预览与编辑

    在地图中缩放、平移、点选要素；可编辑数据在保存前明确展示待提交状态。

  4. 04

    导出所需结果

    根据当前目标输出 CSV、SHP 或新建 GDB，保留清晰的结果边界。

SAFE BY DESIGN

轻量，不等于省略边界。

关键动作保持显式，让你知道正在查看、修改还是生成新结果。

字段校验

编辑值按字段类型验证，问题在写回之前出现。

显式保存

未保存更改保持可见，关闭或切换数据时明确确认。

事务恢复

汇集过程区分写入、核验与提交，避免进度完成但结果尚未落盘。

只读边界

Personal GDB 当前保持只读，查看能力不会伪装成可编辑能力。
