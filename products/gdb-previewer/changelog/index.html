CURRENT RELEASE

V4

2026年8月6日发布

V4 是一次重大版本升级，将 GDB Previewer 从数据查看工具扩展为完整的 Windows GIS 工作空间。本版首次带来全新设置中心、全新符号系统和全新布局制图，并全面增强大型图层预览、属性编辑、数据汇集与校验导出。

全新设置全新符号系统全新布局制图大型数据安全导出

全新功能：统一管理应用设置

  • 新增独立设置中心，集中管理常规偏好、空间预览控制、符号默认值、缓存、诊断、性能日志与高级存储选项。
  • 空间预览控制新增滚轮方向、缩放速度、平移方式、多选修饰键、点击行为，以及固定鼠标与键盘快捷操作。
  • 可分别设置点、线、面图层的默认符号与点选符号，并提供随显示器缩放更新的高清预览。
  • 缓存、配置、日志与符号配置的存储位置可集中管理；更改位置时先复制并校验，再切换到新路径。
  • 缓存清理支持按图例、注记和符号系统显示缓存分别勾选，未选中的缓存不会被删除。
  • 诊断日志与性能日志可按需开启，记录数据源打开、加载、渲染和导出等关键事件，并采用有界轮转控制长期占用。

全新功能：创建、复用并分享真实地图符号

  • 点、线、面图层新增“符号系统”入口，按几何类型提供对应编辑控件与实时预览。
  • 按适用几何支持单一符号、唯一值、分级色彩、二元色彩、未分类连续色彩、分级符号、比例符号、图表和字典共九类符号系统。
  • 唯一值与数值类符号直接分析真实属性字段，支持复合字段、空值、真实范围、分类断点和有界 Fisher-Jenks 分类。
  • 符号由有序的真实图层组成，可逐层编辑 RGBA 颜色、不透明度、标记大小、线宽、显隐、复制、删除与叠放顺序。
  • 图例、编辑预览与地图显示共用同一渲染结果，填充、轮廓、标记、色带与复合符号保持一致。
  • 新增可移植的 .prestyle 样式格式，支持创建、重命名、导入、导出、删除与快速匹配，不依赖 ArcGIS 样式文件。
  • 逐图层符号配置可跨启动恢复，并具备备份恢复能力；样式变化只使相关显示缓存失效，不影响原始几何读取。

全新功能：编排并导出完整地图页面

  • 新增独立布局工作区，支持创建多个命名布局，并可选 A4/A3、纵向或横向纸张。
  • 可添加地图框、标题、图例、比例尺、指北针、自定义文字和标记，并在布局图层列表中管理显隐与顺序。
  • 布局元素支持拖动、缩放、旋转、翻转、锁定、层级调整、多选、分组、撤销、重做与自动保存。
  • 文字支持本机字体、字号、字重、斜体、下划线、颜色及选区级富文本格式，并可完整保留到导出结果。
  • 新增矩形、线段、箭头和多边形整饰对象，支持整页创建、节点编辑、填充与描边样式，以及复制、粘贴和创建副本。
  • 页面边界、中心线、其他元素及矢量节点提供统一吸附参考线，按住 Alt 可临时关闭吸附。
  • 地图框可激活为真实空间预览进行平移、缩放与选取；切换数据源、图层显隐或符号后可刷新内容，不破坏已完成的排版。
  • 整页可导出为 PNG、JPEG、TIFF 或 BMP，支持 96/150/300/600 DPI、背景、JPEG 质量和 TIFF 压缩；地图框按目标分辨率重新渲染。

更完整、更流畅的大型图层显示

  • 大型点、线、面图层从局部细节到全图范围采用分比例尺显示，不以包络矩形或伪图形代替真实几何。
  • 改进帧替换与降级渲染，减少图层局部缺失、空白画面、旧帧残留，以及快速渲染链不可用时的显示中断。
  • 点选、多选、缩放至所选项、属性查看和导出继续读取原始要素标识与原始几何。
  • 选中要素使用独立高亮，未选要素保留原有色相，查看专题图时不会统一变成灰色。
  • 数据加载、图层切换、首帧渲染和可选持久缓存均提供可取消进度；显示缓存不会代替源数据参与查看或导出。

以清晰的待提交流程编辑属性

  • GDB、SHP 与 MDB 属性表继续支持分页、排序、搜索、统计、行选择及地图联动。
  • 可编辑的 FileGDB 与 Shapefile 支持批量更改、撤销、重做、待提交检查、放弃与保存。
  • 异常中断后可恢复编辑草稿；提交前会检测外部变更冲突与写入锁。
  • FileGDB 与 Shapefile 保存后会重新打开并复读校验；MDB 继续限于浏览、预览与导出。
  • 可从空间预览直接编辑图斑属性，并与属性表共享同一批待提交更改及原子保存链路。

经校验的输出，不遗留半成品

  • 可将所选图层批量导出到 Shapefile 目录或新 FileGDB；名称冲突时采用确定性重命名。
  • 可把受支持的 GDB、SHP 与 MDB 数据汇集到新 GDB，并处理字段域、关系、附件及 Feature Dataset 层级等已支持语义。
  • 汇集执行前会列出不支持项与受影响项，让跳过范围明确可见，不做静默忽略。
  • 导出采用临时目标、完整性校验、确定性冲突处理与可回滚替换；取消或失败不会提交半成品。
  • 坐标系缺失时，可明确选择保留原坐标、指定空间参考或取消，不再默认生成语义不明的结果。

全新功能：从数据直接开始

  • 未指定数据源时会进入可操作首页，不再显示用法后直接退出。
  • 可通过选择 GDB 文件夹、选择文件或拖放数据打开 .gdb、.shp 与 .mdb。
  • 最近使用项目支持直接打开、在资源管理器中定位、固定、单独移除或全部清空。

更完整、更稳健的 Windows 桌面版本

  • V4 面向 Windows 10/11 x64，同时提供框架依赖版与自包含版安装程序。
  • 打开或关闭属性表、切换预览与布局、最大化或返回主窗口时，窗口与面板状态更加稳定。
  • 缓存、布局历史、自动保存与符号预览均加入明确的容量、内存或串行执行边界，适合长时间运行。
  • Personal Geodatabase 源数据继续保持只读写回边界；本版本不提供 macOS 或 Linux 版本。
CURRENT RELEASE

V3

2026年6月29日发布

V3 将 GDB Previewer 扩展为同时支持 GDB、SHP 与 MDB 的 Windows 空间数据预览与轻量编辑工具。

GDBSHPMDB轻量编辑

属性、图形与编辑联动

  • 属性表侧栏支持选中行图形预览、宽度调整、折叠与状态记忆。
  • 地图支持按光标缩放、拖动平移和一键适配。
  • 编辑模式按字段类型校验输入，并支持逐步撤销写回。

三种数据格式与完整导出

支持导出属性表 CSV、单个要素 SHP，或将 MDB、GDB、SHP 另存为新的 GDB。

HISTORICAL RELEASE

2026年6月17日发布

V2 建立了面向所有 Windows 用户的安装、更新、修复与卸载流程，并保持 GDB 文件夹的系统集成。

全用户安装维护模式文件关联

统一安装维护入口

  • 安装位置迁移至 Program Files，并使用机器级注册表。
  • 安装器提供安装、更新、修复与卸载四种维护操作。
  • 保留双击与右键打开 GDB 文件夹的系统入口。
