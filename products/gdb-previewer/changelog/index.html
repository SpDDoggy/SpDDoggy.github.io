版本列表

CURRENT RELEASE

V4

2026年8月6日发布

V4 将 GDB Previewer 从数据查看工具扩展为集空间预览、符号系统、布局制图、属性编辑与校验导出于一体的 Windows 工作空间。

大型数据符号系统布局制图安全导出

准确显示与可复用符号

  • 大型点、线、面图层采用分比例尺显示，不以包络矩形或伪图形代替真实几何。
  • 选择、属性查看与导出继续读取原始要素身份和几何，不以显示缓存替代事实数据。
  • 可移植的 .prestyle 样式库支持单一、唯一值、分级、二元、未分类和比例符号工作流。

编排并导出完整地图页面

  • 创建多个 A4 或 A3 布局，加入地图框、标题、图例、比例尺、指北针、文字、标记和矢量整饰对象。
  • 布局元素支持对齐吸附、分组、层级、旋转、节点编辑、撤销重做和自动保存。
  • 整页可导出为 PNG、JPEG、TIFF 或 BMP，最高 600 DPI；地图框会按目标分辨率重新渲染。

事务式编辑与校验输出

  • FileGDB 与 Shapefile 属性支持待提交更改、撤销重做、恢复、冲突检测和保存后复读校验；MDB 保持只读。
  • 批量把所选图层导出为 Shapefile 或 FileGDB，也可将受支持的 GDB、SHP、MDB 数据源汇集到经过校验的新 GDB。
  • 导出采用临时目标、完整性校验、确定性冲突处理和可回滚替换，失败操作不会提交半成品。

完整的桌面入口

  • 全新首页可通过选择或拖放打开 GDB、SHP、MDB，并管理最近使用项目。
  • 设置中心统一管理预览操作、默认符号、缓存位置、诊断信息和受控清理。
  • V4 为 Windows 10/11 x64 提供框架依赖版与自包含版两个安装程序。
CURRENT RELEASE

V3

2026年6月29日发布

V3 将 GDB Previewer 扩展为同时支持 GDB、SHP 与 MDB 的 Windows 空间数据预览与轻量编辑工具。

GDBSHPMDB轻量编辑

属性、图形与编辑联动

  • 属性表侧栏支持选中行图形预览、宽度调整、折叠与状态记忆。
  • 地图支持按光标缩放、拖动平移和一键适配。
  • 编辑模式按字段类型校验输入，并支持逐步撤销写回。

三种数据格式与完整导出

支持导出属性表 CSV、单个要素 SHP，或将 MDB、GDB、SHP 另存为新的 GDB。

HISTORICAL RELEASE

V2

2026年6月17日发布

V2 建立了面向所有 Windows 用户的安装、更新、修复与卸载流程，并保持 GDB 文件夹的系统集成。

全用户安装维护模式文件关联

统一安装维护入口

  • 安装位置迁移至 Program Files，并使用机器级注册表。
  • 安装器提供安装、更新、修复与卸载四种维护操作。
  • 保留双击与右键打开 GDB 文件夹的系统入口。
FIRST RELEASE

V1

2026年5月15日发布

V1 是 GDB Previewer 的首个轻量分发版本，聚焦 File Geodatabase 的快速打开与查看。

GDB 预览用户级安装右键打开

从资源管理器直接打开 GDB

  • 支持双击 GDB 文件夹启动预览器。
  • 提供“用 GDB Previewer 打开”右键菜单。
  • 修复中文批处理分发包在带空格路径下的启动问题。
