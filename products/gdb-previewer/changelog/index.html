GEOPREVIEWER

4.1

2026.09.23

4.1 相比 V4，最大的变化是扩展至 Windows、macOS、Linux，并新增样式资源、分类匹配、地图坐标系与比例尺工具，改进大数据浏览和属性表体验。

本页按 4.1 当前开发状态整理。MDB 属性写回、新版更新弹窗等属于后续开发内容；功能、平台与架构的实际可用性以对应发布安装包为准。

一、新增功能

1. 跨平台支持

  • 桌面架构由 Windows WPF 迁移至 Avalonia，运行环境升级至 .NET 10。新增 macOS Intel、Apple Silicon 及 Linux x64、arm64 平台适配与构建支持，配套原生库加载、安装打包和文件打开注册。Windows 框架依赖版要求 .NET 10 Runtime x64；可下载的平台与架构以实际发布安装包为准。

2. ArcGIS 样式导入

  • 支持读取、浏览和导入 .style、.stylx，按名称、编码、类型和转换状态筛选，预览并多选符号。支持多种点、线、面及适用的文字、指北针、比例尺样式转换，保留来源、原始定义和字体资源。无法转换或缺少必要字体的条目单独标识，不以默认符号代替转换结果。

3. 分类符号匹配

  • 新增独立“匹配分类符号”入口，从已有集合或外部 STYLE、STYLX 文件按分类值、名称等匹配。支持前后对比、唯一候选自动选定、多候选手动选择、逐项更换、筛选与勾选应用范围。唯一值分类可另选属性字段匹配，适用于代码分类与名称样式的对应；外部匹配不会自动将整套资源加入样式库。

4. 样式资源库

  • 采用集合树、资源浏览、预览属性三栏结构，支持集合、分组和子分组，以及点、线、面、颜色组分类浏览。新增重命名、副本、移动、导出、删除及资源和分组右键菜单，支持编辑名称、分类和键，切换网格与列表。未保存修改在切换、关闭或其他操作前可选择保存、放弃或取消。

5. 颜色组资源与编辑

  • 新增连续、离散和二元颜色组管理。连续颜色组支持渐变预览和色标增删、修改、反转；二元颜色组支持矩阵颜色编辑。颜色组可保存复用，应用时仅更新适用的符号颜色，不重建分类字段、分类值或区间。

6. 分类符号批量调整

  • 可同时选择多个分类，批量修改主体颜色与透明度、轮廓颜色与透明度及轮廓宽度，减少逐项打开符号编辑器的操作。

7. 便携样式格式

  • 新增 .gpstyle，保存复杂符号、外部资源、字体及符号来源定义；重复字体资源去重，降低对原始外部文件路径的依赖。

8. 地图显示坐标系切换

  • 新增地图坐标系入口，支持数据原坐标系、WGS 84、Web Mercator、CGCS2000 及适用的 UTM、高斯投影分带；可按名称、EPSG 编码、带号、中央经线和组合关键词搜索。不同坐标系图层可统一显示，切换后同步地图范围、空间查询与选择高亮，仅改变显示，不改写源数据。

9. 地图比例尺工具

  • 新增数字比例尺和可选米／千米线段比例尺；输入分母可围绕地图中心精确缩放。参考比例尺支持设置、返回和清除，符号与标注可随参考比例和当前比例调整显示尺寸。

10. 多底图服务管理

  • 新增左侧底部可折叠底图侧栏，支持多服务叠加、逐服务显隐和拖动排序。影像与注记拆分为独立服务，可分别配置和排序。

11. 底图服务配置库

  • 管理内置配置与多份自定义配置，支持复制、编辑、删除，支持 XYZ 和手动配置的 WMTS。服务可单项或多选添加到地图，按服务配置透明度、显示级别和密钥。保存配置与加入地图分开操作，从地图移除服务不会删除配置。

12. CDF 压缩 GDB 支持

  • 新增 Windows x64 下 CDF 压缩 File Geodatabase 读取，覆盖目录浏览、属性读取、几何预览和要素拾取，解决部分压缩库无法打开或目录可读但地图不显示的问题。

13. MDB 普通属性写回（后续开发）

  • 开发版本支持编辑与保存 MDB 已有记录的文本、Memo、数值等适用普通字段，无需 Access、ACE、ODBC 或 Java。保存时检查源文件和原值冲突，在副本上修改并复读核验后替换原文件；几何、OID 和系统字段不在编辑范围内。实际可用性以对应安装包为准。

14. 布局相关新增

  • 支持导入适用的 ArcGIS 文字、指北针和比例尺样式，并纳入布局保存与重读流程。新增禁用布局选项，可隐藏布局入口，已有布局记录保留。

15. 软件更新（新版流程后续开发）

  • 新增启动后后台检查、运行期间定期检查和手动检查，支持下载、查看更新说明及退出安装。新版提示提供立即更新、跳过此版本、关闭自动更新和稍后处理；按具体版本身份跳过，新构建仍可提示。安装前处理未保存的属性和布局修改，下载及安装前校验文件大小和 SHA-256；新版流程以对应安装包为准。

16. 构建身份识别

  • 显示版本、发布通道与构建编号分开管理，同为“4.1”的开发版、正式版和后续构建可区分新旧；安装程序依据构建身份识别升级、修复和旧包覆盖。

二、性能与体验优化

1. 大数据完整性

  • 移除完整几何读取的 1,000 万要素与 3 亿顶点上限、完整属性读取的 1,000 万行上限，以及正常地图视口的 60,000 要素与 800,000 坐标截断限制，改善首次大范围加载、细部缩小至全图和窗口变化时的数据完整性。

2. 大型 SHP 首次加载

  • 大型线、面 SHP 采用分片并行读取，减少中间坐标集合、重复复制与范围计算，降低仅加载几何时的无关属性处理，并在读取和投影中同步准备后续信息。

3. 重复浏览与分类分析

  • 加强几何、属性、唯一值分析与分类结果复用，减少重复打开图层、选择分类字段时的扫描和相同符号的逐要素解析；条件一致时恢复已完成地图，数据、编辑状态或坐标系变化时使相关缓存失效。

4. 缩放和平移

  • 优化连续输入调度、候选筛选、去重及分类映射，减少等待滚轮停止后才刷新的情况。改进过期请求取消，避免旧请求长期阻塞新视野，修复部分 FileGDB 快速连续缩放后长时间不更新的问题。

5. 复杂地图绘制

  • 分批准备复杂地图绘制内容，扩展准备阶段并行处理，复用画笔、字形和矢量标记，优化纯色填充与多边形组织；渐进显示使已完成图层或批次更早出现。

6. 缓存占用

  • 减少局部视野重叠原始几何落盘，分别控制完整几何缓存与地图画面缓存容量；地图画面同时限制数量和总大小，优先保留较新结果，相关分类更名为“空间预览缓存”。

7. 属性表

  • 优化大表加载、布局和交互；新增行头拖动多选，完善 Ctrl／Shift 选择，多选空间预览适配全部所选要素范围。修复双击被选择事件吞掉而无法编辑的问题，优化按属性选择的建议值后台加载、分页与条件预览。

8. 样式编辑与导入稳定性

  • 修复选择恢复递归导致卡死或退出、切换集合时列表回收引发空引用、重新准备导入覆盖编辑绑定等问题；修复复杂线主体改色误改其他描边、部分面轮廓宽度不生效，改进旧 STYLE 短划线和字符线解析。

9. 地图与布局切换

  • 修复从布局返回同尺寸空间预览时停留旧画面或持续显示渲染状态；从首页空间预览最近项目打开数据时，优先进入空间预览模式。

10. 注记显示

  • 修复注记定位多边形被当作普通面填充，避免文字周围出现多余面框，同时保留文字与要素识别所需几何。

11. SHP 属性错误处理

  • 修复 DBF 缺失、截断或结构不一致被显示为正常空属性的问题，区分合法 NULL、正常结束和读取失败，统一分页、全量及指定字段读取的错误处理。

12. 安装与窗口体验

  • Windows 安装界面显示版本、构建号与进度，完善升级、修复和旧构建识别，升级时读取上次安装任务选项；改进 .NET 10 x64 检测，修复静默升级特定崩溃路径，主窗口在适用显示器工作区居中启动。

三、移除、替换与暂时隐藏

  • 原空间预览底图按钮：隐藏，由底图侧栏承担日常管理。
  • 设置中的旧底图总开关：隐藏，改为逐服务控制显隐。
  • 复合底图配置：替换为单服务配置，影像与注记独立管理。
  • 独立“ArcGIS 库”按钮：移除，统一进入样式库导入流程。
  • 导入与分类应用混合流程：拆分为资源入库和独立分类匹配。
  • 分级符号创建入口：当前编辑器中暂时隐藏，底层代码保留。
  • 比例符号创建入口：当前编辑器中暂时隐藏，底层代码保留。
  • Google 影像、路网预置：当前内置服务目录不再提供。
  • 设置中的自动下载安装选项：新版提示流程移除该选项，更新先由用户选择。
  • 正常地图及完整读取固定数量门槛：移除对应截断限制。
  • 局部视野重叠几何持久缓存：停止按不同局部视野重复落盘。
  • 安装界面内卸载按钮：当前不再提供，使用 Windows 标准卸载入口。
GDB PREVIEWER

V4

2026年8月6日发布

V4 是一次重大版本升级，将 GDB Previewer 从数据查看工具扩展为完整的 Windows GIS 工作空间。本版首次带来全新设置中心、全新符号系统和全新布局制图，并全面增强大型图层预览、属性编辑、数据汇集与校验导出。

全新设置全新符号系统全新布局制图大型数据安全导出

全新功能：统一管理应用设置

  • 新增独立设置中心，集中管理常规偏好、空间预览控制、符号默认值、缓存、诊断、性能日志与高级存储选项。
  • 空间预览控制新增滚轮方向、缩放速度、平移方式、多选修饰键、点击行为，以及固定鼠标与键盘快捷操作。
  • 可分别设置点、线、面图层的默认符号与点选符号，并提供随显示器缩放更新的高清预览。
  • 缓存、配置、日志与符号配置的存储位置可集中管理；更改位置时先复制并校验，再切换到新路径。
  • 缓存清理支持按图例、注记和符号系统显示缓存分别勾选，未选中的缓存不会被删除。
  • 诊断日志与性能日志可按需开启，记录数据源打开、加载、渲染和导出等关键事件，并采用有界轮转控制长期占用。

全新功能：创建、复用并分享真实地图符号

  • 点、线、面图层新增“符号系统”入口，按几何类型提供对应编辑控件与实时预览。
  • 按适用几何支持单一符号、唯一值、分级色彩、二元色彩、未分类连续色彩、分级符号、比例符号、图表和字典共九类符号系统。
  • 唯一值与数值类符号直接分析真实属性字段，支持复合字段、空值、真实范围、分类断点和有界 Fisher-Jenks 分类。
  • 符号由有序的真实图层组成，可逐层编辑 RGBA 颜色、不透明度、标记大小、线宽、显隐、复制、删除与叠放顺序。
  • 图例、编辑预览与地图显示共用同一渲染结果，填充、轮廓、标记、色带与复合符号保持一致。
  • 新增可移植的 .prestyle 样式格式，支持创建、重命名、导入、导出、删除与快速匹配，不依赖 ArcGIS 样式文件。
  • 逐图层符号配置可跨启动恢复，并具备备份恢复能力；样式变化只使相关显示缓存失效，不影响原始几何读取。

全新功能：编排并导出完整地图页面

  • 新增独立布局工作区，支持创建多个命名布局，并可选 A4/A3、纵向或横向纸张。
  • 可添加地图框、标题、图例、比例尺、指北针、自定义文字和标记，并在布局图层列表中管理显隐与顺序。
  • 布局元素支持拖动、缩放、旋转、翻转、锁定、层级调整、多选、分组、撤销、重做与自动保存。
  • 文字支持本机字体、字号、字重、斜体、下划线、颜色及选区级富文本格式，并可完整保留到导出结果。
  • 新增矩形、线段、箭头和多边形整饰对象，支持整页创建、节点编辑、填充与描边样式，以及复制、粘贴和创建副本。
  • 页面边界、中心线、其他元素及矢量节点提供统一吸附参考线，按住 Alt 可临时关闭吸附。
  • 地图框可激活为真实空间预览进行平移、缩放与选取；切换数据源、图层显隐或符号后可刷新内容，不破坏已完成的排版。
  • 整页可导出为 PNG、JPEG、TIFF 或 BMP，支持 96/150/300/600 DPI、背景、JPEG 质量和 TIFF 压缩；地图框按目标分辨率重新渲染。

更完整、更流畅的大型图层显示

  • 大型点、线、面图层从局部细节到全图范围采用分比例尺显示，不以包络矩形或伪图形代替真实几何。
  • 改进帧替换与降级渲染，减少图层局部缺失、空白画面、旧帧残留，以及快速渲染链不可用时的显示中断。
  • 点选、多选、缩放至所选项、属性查看和导出继续读取原始要素标识与原始几何。
  • 选中要素使用独立高亮，未选要素保留原有色相，查看专题图时不会统一变成灰色。
  • 数据加载、图层切换、首帧渲染和可选持久缓存均提供可取消进度；显示缓存不会代替源数据参与查看或导出。

以清晰的待提交流程编辑属性

  • GDB、SHP 与 MDB 属性表继续支持分页、排序、搜索、统计、行选择及地图联动。
  • 可编辑的 FileGDB 与 Shapefile 支持批量更改、撤销、重做、待提交检查、放弃与保存。
  • 异常中断后可恢复编辑草稿；提交前会检测外部变更冲突与写入锁。
  • FileGDB 与 Shapefile 保存后会重新打开并复读校验；MDB 继续限于浏览、预览与导出。
  • 可从空间预览直接编辑图斑属性，并与属性表共享同一批待提交更改及原子保存链路。

经校验的输出，不遗留半成品

  • 可将所选图层批量导出到 Shapefile 目录或新 FileGDB；名称冲突时采用确定性重命名。
  • 可把受支持的 GDB、SHP 与 MDB 数据汇集到新 GDB，并处理字段域、关系、附件及 Feature Dataset 层级等已支持语义。
  • 汇集执行前会列出不支持项与受影响项，让跳过范围明确可见，不做静默忽略。
  • 导出采用临时目标、完整性校验、确定性冲突处理与可回滚替换；取消或失败不会提交半成品。
  • 坐标系缺失时，可明确选择保留原坐标、指定空间参考或取消，不再默认生成语义不明的结果。

全新功能：从数据直接开始

  • 未指定数据源时会进入可操作首页，不再显示用法后直接退出。
  • 可通过选择 GDB 文件夹、选择文件或拖放数据打开 .gdb、.shp 与 .mdb。
  • 最近使用项目支持直接打开、在资源管理器中定位、固定、单独移除或全部清空。

更完整、更稳健的 Windows 桌面版本

  • V4 面向 Windows 10/11 x64，同时提供框架依赖版与自包含版安装程序。
  • 打开或关闭属性表、切换预览与布局、最大化或返回主窗口时，窗口与面板状态更加稳定。
  • 缓存、布局历史、自动保存与符号预览均加入明确的容量、内存或串行执行边界，适合长时间运行。
  • Personal Geodatabase 源数据继续保持只读写回边界；本版本不提供 macOS 或 Linux 版本。

FIRST RELEASE

V1
