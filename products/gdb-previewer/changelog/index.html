CURRENT RELEASE

V4.0.0

最近更新 2026-07-28

V4 持续收拢空间数据的查看、编辑、符号与输出流程。最近一次更新把空间预览与布局图纸拆成两个独立页面，同时强化样式库、汇集事务与字段分析的可靠性。

空间预览布局与出图样式库事务恢复
2026.07.28

空间预览与布局图纸双页

浏览地图和制作图纸成为两个清晰的工作阶段，不再把浏览工具与排版工具堆在同一画布。

  • 空间预览顶部新增互斥的“空间预览 / 布局”切换。
  • 布局页支持 A4/A3、纵向/横向、标题、图例、比例尺和指北针。
  • 布局文档与地图快照自动保存，并支持整页 PNG 导出。
2026.07.26

样式库专用排布与内容编辑

不同渲染器按照符号系统自身语义展示，不再被压成同一种大卡片。

  • 唯一值、单一符号、分级色彩、二元色彩与连续色带获得专用排布。
  • 样式库支持编辑与重命名，并通过原子写入保护原库文件。
2026.07.26

汇集事务进度与恢复

进度明确区分写入、核验与提交，同一目标使用独占事务锁，并可恢复产品生成的静置 staging 结果。

2026.07.23

字段分析与连续数值符号

字段统计改为纯属性分页扫描，唯一值支持文本、数字、日期、布尔值、空值及复合字段。

HISTORICAL RELEASE

V3.0.0

桌面预览与轻量编辑

V3 将 GDB Previewer 扩展为同时支持 GDB、SHP 与 MDB 的 Windows 空间数据预览与轻量编辑工具。

GDBSHPMDB轻量编辑

属性、图形与编辑联动

  • 属性表侧栏支持选中行图形预览、宽度调整、折叠与状态记忆。
  • 地图支持按光标缩放、拖动平移和一键适配。
  • 编辑模式按字段类型校验输入，并支持逐步撤销写回。

三种数据格式与完整导出

支持导出属性表 CSV、单个要素 SHP，或将 MDB、GDB、SHP 另存为新的 GDB。

HISTORICAL RELEASE

V2.0.0

全用户安装版

V2 建立了面向所有 Windows 用户的安装、更新、修复与卸载流程，并保持 GDB 文件夹的系统集成。

全用户安装维护模式文件关联

统一安装维护入口

  • 安装位置迁移至 Program Files，并使用机器级注册表。
  • 安装器提供安装、更新、修复与卸载四种维护操作。
  • 保留双击与右键打开 GDB 文件夹的系统入口。
FIRST RELEASE

V1

首个公开形态

V1 是 GDB Previewer 的首个轻量分发版本，聚焦 File Geodatabase 的快速打开与查看。

GDB 预览用户级安装右键打开

从资源管理器直接打开 GDB

  • 支持双击 GDB 文件夹启动预览器。
  • 提供“用 GDB Previewer 打开”右键菜单。
  • 修复中文批处理分发包在带空格路径下的启动问题。
