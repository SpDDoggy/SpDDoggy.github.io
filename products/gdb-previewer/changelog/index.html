CURRENT RELEASE

V4.0.0

最近更新 2026-07-28

V4 持续收拢空间数据的查看、编辑、符号与输出流程。最近一次更新把空间预览与布局图纸拆成两个独立页面，同时继续强化样式库、汇集事务与字段分析的可靠性。

空间预览 布局与出图 样式库 事务恢复
2026.07.28

空间预览与布局图纸双页

浏览地图和制作图纸成为两个清晰的工作阶段，不再把浏览工具与排版工具堆在同一画布。

  • 空间预览顶部新增互斥的“空间预览 / 布局”切换。
  • 布局页支持 A4/A3、纵向/横向、标题、图例、比例尺和指北针，版面元素可拖动。
  • 只有“同步当前视图”才会更新布局中的地图快照、图例和比例尺，后续浏览不会暗中覆盖已排版内容。
  • 布局文档与地图快照自动保存，并支持整页 PNG 导出和结果尺寸复核。
2026.07.26

样式库专用排布与内容编辑

不同渲染器不再被压成同一种大卡片，预览结构按照符号系统自身语义展示。

  • 唯一值、单一符号、分级色彩、二元色彩与连续色带获得专用排布。
  • 空库首次按几何类型生成可编辑基础测试库，重复打开不会增生。
  • 样式库支持编辑与重命名，并通过原子写入保护原库文件。
2026.07.26

汇集事务进度与恢复

修复对象复制完成就显示 100% 的假完成问题，让进度与最终结果保持一致。

  • 进度明确区分“正在汇集 / 正在核验 / 正在提交”。
  • 同一目标使用独占事务锁，避免并发任务写入同一结果。
  • 启动时可识别、核验并恢复产品生成的静置 staging 结果。
2026.07.24

样式分类与严格依据匹配

样式库只改变表现，不会暗中更换当前专题映射依据。

  • 样式库增加与符号系统选择器一致的分类导航。
  • 严格比较渲染器类型、字段顺序与类型、唯一值集合、断点、范围和矩阵依据。
  • 颜色、透明度、视觉尺寸和图例文字仍允许不同。
2026.07.23

字段分析与连续数值符号

字段统计改为纯属性分页扫描，不再受陈旧范围、空几何或非空间表影响。

  • 唯一值支持文本、数字、日期、布尔值、空值及复合字段。
  • 未分类色彩读取真实最小值、最大值和分布。
  • 二元色彩分别遵循横向与纵向分类方法并生成真实断点。
