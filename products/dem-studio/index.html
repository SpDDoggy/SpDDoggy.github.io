FROM DATA TO TERRAIN

一条完整的地形工作流。

从源高程数据进入可检查的地形场景，再输出带地理参考的结果，全程不离开桌面工作区。

  1. 01
    IMPORT

    导入高程数据

    打开 GeoTIFF/TIFF、SRTM HGT、ASCII Grid 与图像高度图，并读取可用的坐标侧车文件。

  2. 02
    SHAPE

    塑形并检查地形

    实时调整高度、相机、光照、材质、网格质量、平滑与后期效果。

  3. 03
    EXPORT

    导出地理参考结果

    输出 PNG、PNG + World File、GeoTIFF 或 TIFF + World File。

LOCAL-FIRST TERRAIN ENGINE

地形处理，始终贴近数据。

文件处理、渲染、预设与应用状态都保留在本机，核心工作流不依赖云端或 CDN。

01

Rust DEM Core

DEM 解码、NoData 处理、统计、预览抽样、平滑与 GeoTIFF 编码。

02

Three.js / WebGL

可交互地形、相机、材质与光照，并提供独立的渐进式路径追踪通道。

03

Tauri 2

原生文件访问、系统对话框、本地设置、无边框窗口与跨平台打包。

04

文件后备大栅格

已验证的文件后备预览路径，让大幅高程数据无需全部进入界面内存也能查看。
